# رصيد | Raseed

واجهة عربية لإدارة الأموال اليومية للفريلانسر، مبنية كتطبيق ويب ثابت دون خدمات خلفية.

## ما الذي تتضمنه؟

- لوحة تحكم للدخل والمصروفات وصافي التدفق، مع اختيار الريال السعودي أو الريال اليمني أو الدولار.
- حسابات بنكية ومحافظ إلكترونية ورصيد نقدي، مع دعم مزودي حسابات مثل الكريمي والقطيبي والقاسمي ومحفظة جيب.
- سجل دخل ومصروف وتحويل بين حسابين بالعملة نفسها، مع وصف وتصنيف وجهة وملاحظات.
- ديون مستحقة لك والتزامات عليك، مع تسجيل التحصيل والسداد وتحديث رصيد الحساب تلقائيًا.
- تقارير شهرية وكشوف CSV قابلة للتنزيل، وفلاتر للبحث والتاريخ والنوع والعملة.
- بيانات عرض أولية يمكن مسحها من زر «ابدأ ببياناتي» في لوحة التحكم.

## التشغيل

افتح `index.html` في متصفح حديث، أو استضف الملفات الثابتة عبر GitHub Pages. لا يحتاج المشروع إلى تثبيت حزم أو بناء.

## حدود النسخة

- تُحفظ البيانات في `localStorage` على المتصفح والجهاز الحالي فقط. لا توجد مزامنة أو حسابات مستخدمين أو نسخ احتياطي سحابي.
- لا يوجد ربط مباشر بالبنوك أو المحافظ، ولا يتم تحويل العملات تلقائيًا.
- يبدأ التطبيق بسجلات توضيحية. قبل إدخال بيانات فعلية، استخدم «ابدأ ببياناتي» لمسح بيانات العرض والبدء بحسابات فارغة.
- تنزيل CSV متاح لحفظ نسخة من العمليات خارج التطبيق.

## الملفات

- `index.html` — نقطة الدخول وهيكل التطبيق.
- `styles.css` — الواجهة العربية المتجاوبة.
- `app.js` — الحسابات والتفاعلات والتقارير والحفظ المحلي.
