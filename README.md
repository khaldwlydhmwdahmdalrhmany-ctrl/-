# رصيد | Raseed

تطبيق عربي لإدارة المال اليومي للمستقلين، يعمل محليًا على الجهاز دون ربط مصرفي.

## بداية الاستخدام

1. أنشئ ملفك المالي باسمك أو اسم نشاطك واختر عملة العرض الافتراضية.
2. أضف الحسابات البنكية والمحافظ والنقدية، وسجّل الرصيد الموجود في كل حساب.
3. أضف الديون والمبالغ المستحقة لك أو عليك، ثم انتقل إلى لوحة التحكم.

## إدارة العمل والمال

- لوحة تحكم للدخل والمصروفات والأرصدة حسب العملة.
- حسابات بالريال السعودي والريال اليمني والدولار، مع النقد والبنوك والمحافظ مثل الكريمي والقطيبي والقاسمي وجيب.
- عمليات دخل ومصروف وتحويل، مع وصف وتصنيف وعميل ومشروع وحساب وتاريخ وملاحظات.
- سجل ديون منفصل للمبالغ المستحقة لك والالتزامات عليك، مع تسجيل التحصيل والسداد.
- صفحات مستقلة لإدارة المشاريع والعملاء. تعرض المشاريع قيمتها والدفعات المحصلة والمتبقي ومصروفاتها.
- تقارير شهرية وكشوف عمليات قابلة للتنزيل بصيغة CSV.
- واجهة متجاوبة مع الهاتف، ودعم PWA للعمل دون اتصال بعد فتح رابط HTTPS مرة واحدة.
- APK Android يحزم الواجهة محليًا ويعمل دون اتصال.

## الخصوصية وحدود التطبيق

- البيانات محفوظة محليًا على الجهاز الحالي. لا توجد مزامنة أو حساب سحابي أو استعادة تلقائية عند تغيير الهاتف.
- التطبيق لا يتصل بالبنوك أو المحافظ؛ أدخل الأرصدة والعمليات يدويًا.
- العملات مستقلة ولا تُحوّل تلقائيًا بينها.
- يحتوي التطبيق على تنزيل CSV للعمليات. احتفظ بنسخة من سجلاتك قبل تغيير الجهاز أو حذف التطبيق.

## البناء والنشر

يُبنى APK عبر GitHub Actions عند كل تحديث لفرع `main`. نزّل الأرشيف `raseed-android-apk` من صفحة Actions؛ يحتوي على `app-debug.apk` قابل للتثبيت اليدوي.

لنشر نسخة الويب، فعّل GitHub Pages مرة واحدة من **Settings → Pages → Build and deployment → GitHub Actions**. بعدها ينشر الـWorkflow التحديثات تلقائيًا.
