# رصيد | Raseed

تطبيق عربي لإدارة المال اليومي للمستقلين، يعمل محليًا على الجهاز دون ربط مصرفي.

## بداية الاستخدام

1. أنشئ ملفك المالي باسمك أو اسم نشاطك واختر عملة العرض الافتراضية.
2. أضف الحسابات البنكية والمحافظ والنقدية، وسجّل الرصيد الموجود في كل حساب.
3. أضف الديون والمبالغ المستحقة لك أو عليك، ثم انتقل إلى لوحة التحكم.

## إدارة العمل والمال

- لوحة تحكم للدخل والمصروفات والأرصدة حسب العملة.
- حسابات بالريال السعودي والريال اليمني والدولار، مع النقد والبنوك والمحافظ والصرافين مثل الكريمي والقطيبي والقاسمي وجيب وشيلن.
- عمليات دخل ومصروف وتحويل داخلي ومصارفة بين عملتين ورسومها، مع وصف وتصنيف وجهة ومشروع وحساب وتاريخ وملاحظات. يمكن ربط مصروف أو التزام بتكلفة دخل محدد لمعرفة صافي عائده.
- سجل جهات للأفراد والعملاء والشركات والمتعاونين والموردين، ومتابعة ما لك وما عليك لكل شخص وربطه بمشروع أو تكلفة. عند تسجيل التزام، اختر احتسابه كمصروف مستحق الآن أو تسجيل المصروف عند الدفع؛ السداد الجزئي يحدّث المتبقي.
- رواتب ومصروفات شهرية متكررة تُسجل يدويًا عند القبض أو الدفع حتى لا تُسجل حركة مالية لم تحدث. تعرض لوحة التحكم مقارنة شهرية ومخططًا لآخر ستة أشهر.
- تصنيفات قابلة للإضافة والتعديل، وتقارير شهرية حسب العملة أو كشف حركة ورصيد لحساب محدد.
- تصدير CSV للكشوف مع كشف حساب ذي رصيد افتتاحي وحركة ورصيد ختامي، وطباعة التقارير، ونسخة JSON كاملة يمكن استعادتها على الجهاز.
- واجهة متجاوبة مع الهاتف، ودعم PWA للعمل دون اتصال بعد فتح رابط HTTPS مرة واحدة.
- APK Android يحزم الواجهة محليًا ويعمل دون اتصال.

## الخصوصية وحدود التطبيق

- البيانات محفوظة محليًا على الجهاز الحالي. لا توجد مزامنة أو حساب سحابي؛ نزّل نسخة JSON من صفحة التقارير قبل تغيير الهاتف أو حذف التطبيق، ثم استعدها في النسخة الجديدة.
- التطبيق لا يتصل بالبنوك أو المحافظ؛ أدخل الأرصدة والعمليات يدويًا.
- العملات مستقلة ولا تُحوّل تلقائيًا بينها.

## البناء والنشر

يُبنى APK عبر GitHub Actions عند كل تحديث لفرع `main`. نسخة Android الحالية 1.3.0 (versionCode 4). نزّل الأرشيف `raseed-android-apk` من صفحة Actions؛ يحتوي على `app-debug.apk` قابل للتثبيت اليدوي. لها معرّف تطبيق مستقل لتثبيتها بجانب النسخة السابقة مع إبقاء بياناتها كما هي؛ ابدأ إعداد التطبيق الجديد ثم استعد نسخة JSON من صفحة التقارير.
