# رصيد | Raseed

واجهة عربية لإدارة الأموال اليومية للفريلانسر، مبنية كتطبيق ويب ثابت مع نسخة Android مستقلة.

## ما الذي تتضمنه؟

- لوحة تحكم للدخل والمصروفات وصافي التدفق، مع اختيار الريال السعودي أو الريال اليمني أو الدولار.
- حسابات بنكية ومحافظ إلكترونية ورصيد نقدي، مع دعم مزودي حسابات مثل الكريمي والقطيبي والقاسمي ومحفظة جيب.
- سجل دخل ومصروف وتحويل بين حسابين بالعملة نفسها، مع وصف وتصنيف وجهة وملاحظات.
- ديون مستحقة لك والتزامات عليك، مع تسجيل التحصيل والسداد وتحديث رصيد الحساب تلقائيًا.
- تقارير شهرية وكشوف CSV قابلة للتنزيل، وفلاتر للبحث والتاريخ والنوع والعملة.
- بيانات عرض أولية يمكن مسحها من زر «ابدأ ببياناتي» في لوحة التحكم.
- تثبيت كتطبيق ويب (PWA) مع أيقونة وتشغيل دون اتصال بعد فتحه مرة عبر رابط HTTPS.
- بناء APK تلقائيًا عبر GitHub Actions وتشغيل التطبيق دون اتصال من ملفات محلية داخل Android WebView.

## التشغيل

لنشر نسخة الويب، فعّل GitHub Pages مرة واحدة من **Settings → Pages → Build and deployment → GitHub Actions**. بعدها ينشر الـWorkflow نسخة HTTPS تلقائيًا؛ افتح الرابط في Chrome على Android واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». على iPhone استخدم «إضافة إلى الشاشة الرئيسية» من قائمة Safari. بعد تحميل ملفات التطبيق أول مرة، يحفظ PWA نسخة تعمل دون اتصال.

يُبنى APK تلقائيًا عند كل دفع إلى `main` من خلال GitHub Actions. نزّل ملف `app-debug.apk` من قسم Artifacts في تشغيل Workflow باسم **Build Raseed APK and publish web app**. APK موقّع بمفتاح debug القياسي للتثبيت اليدوي. لا ترفع بياناتك المالية إلى المستودع.

## حدود النسخة

- تُحفظ البيانات في مساحة التطبيق على الجهاز الحالي فقط. لا توجد مزامنة أو حسابات مستخدمين أو نسخ احتياطي سحابي.
- لا يوجد ربط مباشر بالبنوك أو المحافظ، ولا يتم تحويل العملات تلقائيًا.
- يبدأ التطبيق بسجلات توضيحية. قبل إدخال بيانات فعلية، استخدم «ابدأ ببياناتي» لمسح بيانات العرض والبدء بحسابات فارغة.
- تنزيل CSV متاح لحفظ نسخة من العمليات خارج التطبيق.
- APK لا يتطلب اتصالًا بالإنترنت بعد تثبيته. تحديثات التطبيق تتطلب تثبيت APK أحدث، وقد يطلب Android إزالة النسخة السابقة إذا تغيّر مفتاح التوقيع.

## الملفات

- `index.html` — نقطة الدخول وهيكل التطبيق.
- `styles.css` — الواجهة العربية المتجاوبة.
- `app.js` — الحسابات والتفاعلات والتقارير والحفظ المحلي.
- `manifest.webmanifest` و`sw.js` و`icons/` — إعدادات التثبيت والعمل دون اتصال للويب.
- `android/` — مشروع Android الذي يحزم الواجهة داخل APK.
